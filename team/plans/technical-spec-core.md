# Technical Spec — core rulings (condensed, 2026-08-13; binding on the build)

## Rulings (single source of truth; phase-1/phase-3 docs defer here)
- **App mode = tiny local server** (`src/server.js`, ~90 lines, zero deps, 127.0.0.1 only, port 4317): file:// can't fetch bundles and `<audio>` seeking needs Range/206 — a plain server makes click-to-play testable. Viewer module identical across app/tier-1/tier-2 modes.
- **Coverage bands** (computed in gate.js; UI renders `notes.coverage.band`, never recomputes): blocked only when a REQUIRED section (summary, next_steps) had attempted claims and 0 verified → `GATE_BLOCKED_UNPROVEN_CLAIMS` (no notes, rejected.json only). Else: extractor failures → PARTIAL_EXTRACTORS_FAILED; ratio <0.50 → PARTIAL_LOW_COVERAGE (loud banner); 0.50–0.80 → PARTIAL_CLAIMS_DROPPED; ≥0.80 → SHIPPED (+_WITH_CORRECTIONS if any segment_corrected). `attempted==0` is a VALID quiet call → SHIPPED, ratio:=1. **Injection-blocked claims are excluded from the denominator** (else the planted-injection call reads PARTIAL for the wrong reason).
- **`claim.status = verified | segment_corrected | uncorroborated | blocked_injection`** — blocked_injection evaluated FIRST and cannot fold into uncorroborated (the planted line IS in the transcript; anchoring passes; that's exactly why a second independent screen exists). Per-evidence `match_type = exact | exact_pm1 | normalized | segment_corrected | none`.

## The gate chain (pure, offline, `src/gate.js` + `src/injection.js`)
Injection screen first (taint via deterministic patterns + smuggled-URL/imperative checks) → exact indexOf in cited utterance ±1 → normalized containment same window (NFKC, fold typographic variants, collapse ws, casefold — **NEVER digits/number-words**) → long-unique whole-transcript rescue (≥60 chars/10 tokens, unique or prefix/suffix-disambiguated, relabeled segment_corrected, counted) → none. **Ties resolve to null, never a guess.** Min quote 15 normalized chars. Claim never blocks the run (demote visibly).

## Extraction runner (`src/extract.js`)
Registry loads/validates/freezes extractor JSONs at STARTUP (name=filename; `model` key FORBIDDEN — role only, L12; portability lint = Anthropic∩OpenAI schema subset; evidence-reachability lint). Evidence = `{utterance_id, quote}` only, evidence-before-claim key order. **Supplied-ID screen: any cited id not shown to the model rejects the WHOLE response** (ungrounded generation poisons all items) — fixable, consumes one of 2 repairs. Repairs carry literal validator text + echo the bad output back. Truncation (`max_tokens`) and refusal are their own exits, NEVER repaired. Transport retries (4, jitter, Retry-After floor) separate from semantic repairs (2, no wait).

## Model calls (raw fetch, `src/llm.js`, mirrors pyai.js; SDK not used — zero deps)
NEVER send temperature/top_p/top_k (400 on Sonnet 5). Set `thinking` explicitly (omitted = adaptive = silently eats max_tokens). Structured outputs via `output_config.format`; incompatible with Anthropic Citations (400) — we rebuilt the citation contract ourselves. `max_tokens` 8000 headroom. Email role NEVER sees the transcript (choke point): input = verified claims only; uncited bullets cut in code; unknown claim_id → whole draft rejected.

## Run records: write-ahead run.json BEFORE first spend; single-writer queue + temp-rename (two different problems); heartbeat + sweeper (no state is permanently "in progress"); exit_reason written ONCE (first reason wins); SIGINT handler must process.exit(130) itself; ~28 named exits with what each leaves behind. CLI final line: `run … → SHIPPED_WITH_CORRECTIONS (13/14 verified, 1 corrected, 1 neutralized) in 79s, $0.063, exit 0`.

## Build slices: S1 walking skeleton ~3h (gate FULL + injection FULL first — offline-testable before any key; registry; prompt; llm; runner; run records; minimal viewer with ONE working click-claim) → S2 width ~2.5h (4 extractor FILES zero code changes; governor; email; server+audio; exports; full exits) → S3 polish (tier-2 fragment; SQLite FTS — cut-first). Gate/injection/prompt/registry are FULL in S1 and never touched again. D4 note: $10 Anthropic cap ≈ 100 full demo-corpus runs; default demo path spends $0.
