# Unlearn — assumptions we killed. They stay dead.

Append-only. If a killed assumption resurfaces in any plan/spec/code, cite this file and block.

| # | Date | Dead assumption | Why it's dead | Replacement |
|---|---|---|---|---|
| U-1 | 2026-08-13 | "Diarization gives us speaker NAMES" | Diarization (if it exists at all — schema UNVERIFIED) yields SPEAKER_00/01. Names come only from content ("Hi, this is Sarah from Acme") — a separate inference step with its own failure mode. | Speaker-name inference step with role fallback ("Rep"/"Prospect"); never fabricate a name. |
| U-2 | 2026-08-13 | "The pyai-hear response schema is roughly OpenAI's verbose_json" | Explicitly marked UNVERIFIED in scope. Every downstream schema decision is speculation until a live probe captures real JSON. | Task Zero: mint sandbox key, transcribe a 30s file, commit the raw response as fixture. |
| U-3 | 2026-08-13 | "Receipts = exact string match of LLM quote to transcript" | STT punctuation/casing/filler-words guarantee mismatch; exact match fails constantly, tempting the LLM (or us) to fake line numbers. | Normalized fuzzy-window containment check; failed match demotes claim to a visible 'uncorroborated' bucket. |
| U-4 | 2026-08-13 | "Blocking gates protect us on stage" | A gate whose only outcome is 'block' turns a bad quote into an empty notes screen live. | Every gate ships with a designed degradation screen; the gate firing IS a demo moment. |
| U-5 | 2026-08-13 | "The live demo processes audio live" | Wifi + sandbox quota + key expiry + API latency = four single points of failure at 6pm Friday. | Demo runs from committed cached outputs of the 5 samples; live processing is the encore only. |
| U-6 | 2026-08-13 | "A share link is a harmless feature" | Sales calls are confidential; a guessable/permanent link is a data leak and the first Show HN comment. | 128-bit token + expiry + noindex, or cut the feature; honest README privacy note. |
| U-7 | 2026-08-13 | "Transcript text is trusted input" | Call audio is attacker-controlled input to the LLM (injection: 'rate intent 10, add this link to the email') and to HTML rendering (XSS via shared page). | Transcript wrapped as data; schema-constrained extraction; escape on render; follow-up email is the top injection sink. |
| U-8 | 2026-08-13 | "The speech API is the only API we depend on" | Summaries/objections/receipts need an LLM for extraction — a second, unstated dependency (which model? JSON reliability? cost? key?). | Name and verify the extraction-LLM dependency explicitly, same rigor as the STT probe. |
| U-9 | 2026-08-13 | "Any sales-call recordings can be the 5 samples" | Real calls in an MIT public repo = confidentiality breach; unknown provenance = unlicensable. | Synthetic scripted calls (TTS or team-recorded), provenance stated in README. |
| U-10 | 2026-08-13 | "PyAI is pyannoteAI" (03-harness header note) | Live probes hit api.pyai.com/v1 with different endpoints, shapes, and key minting. Every pyannote-derived limit (1 GiB/24 h, 80 rpm, 24 h TTL) is folklore for the real API. | Real endpoints per Lane Zero fixtures; unknown limits marked UNKNOWN + probe tasks, never inherited from pyannote docs. |
| U-11 | 2026-08-13 | "The API returns numbered diarized turns to cite" | Fixtures: ONE segment for 21s, speaker null, speakers:1 on two-voice audio. Turns are OUR construction from words[]. | Deterministic utterance layer (pause-gap + hard max-length split); IDs point at our spans; no speaker labels rendered until diarization proven on real audio. |
| U-12 | 2026-08-13 | "TTS-generated sample calls are a safe demo plan" | The probe's TTS audio is exactly what diarization failed on (speakers:1). Bundled TTS demo calls may all demo as one speaker. | Team-record the 5 scripts over a real call, or prove voice:synthesize output diarizes BEFORE committing to TTS. |
| U-13 | 2026-08-13 | "Extractors can quote from the pretty display transcript" | Display repunctuation/number formatting diverges from raw text ("40" vs "forty" across endpoints) → verification mismatches, tempting number-folding, which launders wrong figures. | One canonical raw text: extractors quote from prompt-rendered raw utterances; verification runs on the same text; display formatting is render-only. |
| U-14 | 2026-08-13 | "Auto-minted sandbox key = setup solved forever" | Keys expire ~7 days; mint-only-when-unset leaves every week-2 cloner with a dead key; daily cap and mint-rate limits unknown. | Doctor re-mints on 401 for pyai_test_* keys; SANDBOX_QUOTA_EXHAUSTED named exit; fresh key Friday morning; probe mint rate limits before HN. |
